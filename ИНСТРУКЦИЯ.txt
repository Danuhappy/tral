ТРАЛ-РАСЧЁТ: как выложить приложение и поставить на телефоны
==============================================================

В архиве готовое приложение. Его нужно один раз выложить в интернет,
после чего оно ставится на любой iPhone и Android как обычное приложение
и работает даже без интернета.

ШАГ 1. Выложить в интернет (бесплатно, через GitHub Pages)
--------------------------------------------------------------
1. Распакуй архив на компьютере.
2. Зайди на github.com и зарегистрируйся (Sign up). Имя аккаунта будет в ссылке,
   например kentavr-tral.
3. Справа вверху «+» -> New repository.
   - Repository name: tral
   - Отметь Public
   - Нажми Create repository.
4. На странице репозитория нажми ссылку «uploading an existing file».
5. Перетащи в окно ВСЁ содержимое распакованной папки: index.html, sw.js,
   manifest.webmanifest, settlements.json и папку icons целиком.
   Внизу нажми Commit changes.
6. Открой Settings -> Pages (в меню слева).
   - Source: Deploy from a branch
   - Branch: main, папка / (root) -> Save.
7. Подожди 1–3 минуты и обнови страницу. Появится ссылка вида:
   https://ИМЯ-АККАУНТА.github.io/tral/
   Это адрес твоего приложения.

ШАГ 2. Поставить на телефон
--------------------------------------------------------------
iPhone:
 1. Открой ссылку именно в Safari.
 2. Нажми кнопку «Поделиться» (квадрат со стрелкой вверх).
 3. Выбери «На экран "Домой"» -> «Добавить».
 Появится иконка Трал-Расчёт.

Android:
 1. Открой ссылку в Chrome.
 2. Меню (три точки справа вверху) -> «Установить приложение»
    или «Добавить на главный экран».

После первого открытия с интернетом приложение работает и без сети:
расчёты, справочник населённых пунктов, карта трасс.

ШАГ 3. Разослать водителям и логистам
--------------------------------------------------------------
Просто отправь им ссылку из шага 1, пусть сделают шаг 2.

ВАЖНО ПРО ДАННЫЕ
--------------------------------------------------------------
- Расчёты, сохранённые грузы, препятствия и настройки хранятся на каждом
  телефоне отдельно, между телефонами они не синхронизируются.
- Раз в неделю делай резервную копию: «Расходы и настройки» ->
  «Сохранить копию в файл». Файл отправь себе в Telegram.
  Восстановить: там же -> «Восстановить из файла».
- Кнопки «Совет Claude» в этой версии нет: она работает только внутри Claude.

КАК ОБНОВИТЬ ПРИЛОЖЕНИЕ
--------------------------------------------------------------
Когда я сделаю новую версию, загрузи новые файлы в тот же репозиторий
(Add file -> Upload files, с заменой). Телефоны подхватят обновление
при следующем открытии с интернетом (иногда нужно открыть приложение дважды).
